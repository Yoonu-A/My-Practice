C Programming Language

C is a powerful general-purpose programming language. It is widely used for system programming, software development and embedded systems.

Introduction to C

C is one of the most popular programming languages. It was developed by Dennis Ritchie.

Features of C

  • Simple and fast
  • Portable
  • Structured programming
  • Rich set of operators
  • Supports pointers

Basic C Syntax

#include <stdio.h>

int main() {
    printf("Hello World");
    return 0;
}

Variables

A variable is used to store data in a program. 

int age = 21;
float price = 10.5;
char grade = 'A';

Data Types

Data Type Example
int 10
float 10.5
char 'A'

Operators

C supports arithmetic, relational, logical and assignment operators. 

int a = 10;
int b = 5;

printf("%d", a + b);

Conditions

int age = 20;

if (age >= 18) {
    printf("Adult");
}

Loops

Loops are used to repeat a block of code.

for(int i = 1; i <= 5; i++) {
    printf("%d", i);
}

Functions

Functions are reusable blocks of code. 

void hello() {
    printf("Hello");
}
