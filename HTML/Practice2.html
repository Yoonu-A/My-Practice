Web Development

Web Development involves building and maintaining websites and web application.
it is categorized into three main branches: front-end(client-side user interfaces), back-end(server-side logic,databases,and APIs),and full stack(mastering both)

  • Core Front-end Technoligics

The visible parts of a website are built using three fundementals languages:

  • HTML (Hyper Text Markup Languages):
    • Provides the basic structure and content of a web page.
  • CSS (Cascading Style Sheets):
    • Controls the visual stying,including colors,fonts,and responsive layouts for mobile or desktop viewing.
  • Java Script (JS):
    • Adds interractivity,such as animations,dynamic content updates,and API data fetching.
